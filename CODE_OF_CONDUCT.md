# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, welcoming and constructive; no harassment,
discrimination, or personal attacks; critique code and results, not people.
Maintainers may remove contributions and restrict participation that break these
rules.

Report violations privately through
<https://github.com/sachncs/tinylm/security/advisories/new> (mark it as a
conduct report) or by email to the maintainer listed in the git history.
